# Подключение сообщества бота 242305804

Работаем с https://vk.ru/club242305804. Для бота нужен ключ именно этого
сообщества. Ключи сообществ, куда публикуются посты, подключаются отдельно.

## Настройки сообщества

В управлении сообществом:

1. Включите «Сообщения сообщества».
2. В разделе «Сообщения» → «Настройки для бота» включите «Возможности ботов».
   Это необходимо для кнопок меню; одного включения Long Poll недостаточно.
3. В «Работа с API» → «Long Poll API» включите Long Poll.
4. В типах событий включите входящие сообщения (`message_new`).
5. Выберите версию API 5.199, если доступна в списке.
6. В разделе ключей доступа создайте ключ для сообщений и фотографий.
   Если интерфейс отдельно предлагает управление сообществом, право потребуется
   проверить для получения Long Poll сервера; точную ошибку покажет --check.

Названия пунктов могут отличаться в интерфейсе ВК. Для кнопок используются
текстовые события message_new, а не callback message_event.
Возможности публикации на стене этому ключу добавлять не нужно.

## Обновление существующей установки

Сначала определите способ установки по [инструкции обновления](server-update.md).
Примеры ниже рассчитаны на запуск от root; если проект принадлежит системному
пользователю `publikot`, выполняйте команды Python от этого пользователя.

Если бот запущен в терминале, сначала Ctrl+C. Если уже есть служба systemd,
выполните `systemctl stop publikot`.

```sh
cd /opt/publikot
git pull --ff-only origin master
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/setup-python.py
```

Ключ вводится скрыто локально на сервере. Не присылайте его в чат. Для сообщества
оставьте 242305804. Если не знаете ID личного профиля, оставьте поле пустым.

```sh
.venv/bin/python -m publikot --check
.venv/bin/python -m publikot --identify
```

Отправьте /id в сообщения сообщества. Команда выведет ID отправителя и завершится.
Выберите свой ID, если ботом пользуется несколько человек. Повторно выполните
скрипт настройки: Enter сохранит ключ, в поле ID введите свой числовой ID ВК.

```sh
.venv/bin/python scripts/setup-python.py
.venv/bin/python -m publikot
```

Отправьте /start. Ожидается главное меню, а не запрос допуска. Для проверки
выберите «Добавить сообщество» или «Мои сообщества». Старые команды тоже работают:

```text
/new Тестовый бренд
/concept Небольшая кофейня
/post Расскажи о новом меню
```

Бот пришлёт демо-текст и кнопки. Исправьте текст, замените фото, отмените задание.
Демо-публикация заблокирована. Один токен сообщества — один запущенный процесс.
Режим --identify и постоянный бот одновременно не запускаются.

## Если не работает

- --check: ошибка API 5 — проверьте ключ; 7/15 — права доступа.
- Нет сообщений — включение Bots Long Poll, событие message_new, правильный ID
  сообщества; напишите в личные сообщения, а не в комментарии или беседу.
- Просит допуск — OWNER_VK_ID должен содержать ваш ID ВК, не Telegram ID.
- Кнопки не появились — включите возможности ботов в сообщениях сообщества.
- Бот видит события, но не отвечает: посмотрите метод и код ошибки в терминале.
  `messages.send`, API 912 — включите «Возможности ботов»; API 901/902 —
  разрешите сообщения от сообщества; API 5 — проверьте ключ бота.
  При API 912 на отправку меню бот попытается прислать объяснение без кнопок.
  После исправления отправьте новый `/start`: неуспешное событие автоматически
  не повторяется. `/id` проверяет простой текстовый ответ без клавиатуры.
- Секреты и полный .env.python в переписку не отправляйте.

Реальный запуск считается проверенным только после получения /start и полного
тестового цикла с вашим ключом. Локальные тесты не подтверждают права аккаунта.
