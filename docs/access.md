# Доступ к боту и назначения проектов

OWNER_VK_ID в .env.python — ID администратора. Он управляет доступом,
но в обычных командах получает только назначенные ему проекты.
Пользователи узнают свой ID командой /id, даже до допуска к боту.
Разрешения и назначения хранятся в SQLite и сохраняются при перезапуске.

В главном меню администратора «Управление доступом» содержит «Разрешить доступ»,
«Запретить доступ», «Участники бота» и «Главное меню». Назначение и снятие
проектов доступны командами `/assign` и `/unassign`.
В меню сообщества «Настройки проекта» открывает концепцию, правила текста,
персонажей и параметры генерации. Манера речи и оформление задаются в концепции.
Каждый раздел показывает текущее
состояние; «Добавить» открывает ввод, «Назад» возвращает к предыдущему уровню.
Для персонажей сохраняется строго одно фото.
Новое фото заменяет старое. Можно приложить описание в подписи.
Пункты «Промпт для текста» и «Промпт для изображения» сразу содержат базовые
шаблоны. Откройте пункт, нажмите «Изменить» и отправьте новый текст.
Изменяется только выбранный проект; пустой промпт сохранить нельзя.
Концепция, правила, материалы и задание подставляются автоматически
после текста шаблона. Изменения используются при следующем создании или
перегенерации задания; ранее сохранённые версии не меняются.
При обновлении существующие проекты тоже получают оба базовых промпта.

Удаление: «Настройки проекта» → «Удалить проект» → «Да, удалить».
Кнопка доступна владельцу проекта и администратору бота; назначенный участник
не может удалить чужой проект. «Назад» отменяет подтверждение.
Удаляются записи проекта, его материалы и настройки, задания со всеми версиями,
назначения участников, OAuth-сессии и сохранённый ключ. Опубликованные посты VK
остаются. Файлы изображений в каталоге данных и резервные копии автоматически
не очищаются. Удаление недоступно, пока выполняется генерация или публикация.

## Пример

Предположим, ваш ID — 111111111, ID сотрудника — 222222222.
Команды выполняются в личных сообщениях сообщества бота, когда бот уже запущен:

```text
/allow 222222222
/new Кофейня
/allprojects
```

Бот вернёт номер проекта. Если это 1:

```text
/assign 1 222222222
```

Сотрудник отправляет:

```text
/projects
/select 1
/settings
/concept Наша кофейня и её аудитория. Дружелюбная речь без канцелярита. Светлые фоны и мягкие тени.
/textprompt Пиши коротко, без выдуманных фактов
/imageprompt Иллюстрация в пастельных тонах
```

Фото персонажей отправляет с подписью `/character Рыжий лис в синем шарфе`.
Команда заменяет единственное фото персонажей.
`/characters` показывает сохранённое фото персонажей.
Раздела референсов проекта больше нет. Референс можно приложить к заданию,
например фото с подписью `/post Расскажи о нашем кофе. Замени фон фото на синий`.
Без фото задание тоже работает. Референс не включается в публикацию автоматически.
В версии задания сохраняются два промпта и пути фото с ролями style, character,
reference. Их тексты доступны по кнопке «Промпты» в предпросмотре.
Фото не анализируются текстовой моделью; для конкретных деталей нужна подпись.
Адаптер генерации/редактирования изображений ещё не подключён.

При обновлении из старой версии для раздела персонажей выбирается последнее
сохранённое фото проекта. Старые таблицы персонажей и референсов сохраняются
в базе как архив, но больше не используются для новых промптов.

Задания общие для назначенных участников: /jobs показывает последние 30,
/job НОМЕР открывает выбранное задание, /status — текущее.
Любой участник может редактировать и подтверждать материал своего проекта.

## Администратор как участник

При создании проекта администратор назначается в него автоматически.
Можно снять это назначение командой `/unassign 1 111111111`, не теряя управление
проектами. Обратное назначение: `/assign 1 111111111`.
/projects — рабочие проекты; /allprojects — все проекты для управления.

## Отзыв доступа

- `/unassign 1 222222222` — убрать один проект.
- `/deny 222222222` — запретить использование всего бота. Список назначений
  сохраняется; повторный /allow возвращает доступ к сохранённым назначениям.
- `/members 1` — участники проекта; `/users` — допущенные пользователи.

Удаление доступа блокирует новые команды и кнопки. Уже начатый внешний запрос
нельзя отменить этим действием. Данные проекта при отзыве доступа не удаляются.

## Ключи ВК и расходы ИИ

Основной сценарий: «Мои сообщества» → «Добавить сообщество» сразу открывает
авторизацию VK в браузере. Войдите тем же аккаунтом, из которого пишете боту,
разрешите доступ и выберите сообщества в открывшемся списке.
Кнопка имеет тип open_link: промежуточного запроса ссылки или ключа в чате нет.
Бот проверяет права редактора или администратора и сохраняет ключ зашифрованным.
Повторное добавление обновляет подключение и сохраняет настройки проекта.
Используется приложение 54825715 с разрешениями wall/photos/groups и callback
`https://bot.itiscat.ru/oauth/vk/callback`. Настройка сервера:
`.venv/bin/python scripts/configure-oauth.py --provider vkid`.
Ссылка авторизации действует 10 минут: если устарела, заново откройте «Мои сообщества».
Статус: /connection. Отключение: /disconnect.

Сохраняйте базу и `data/oauth.key` вместе: файл необходим для расшифровки
ключей после восстановления. Ключ не выводится в ответах и сообщениях об ошибке.
Ранее сохранённые подключения продолжают использоваться. При истечении или отзыве
ключа повторите добавление через авторизацию VK.

Ключи не отправляются в чат. Администратор вводит их локально в .env.python:
`VK_ACCESS_TOKEN_PROJECT_1` — ключ для проекта 1, аналогично для других номеров.
Назначенные участники используют его для этого проекта. Ключ должен иметь
минимально необходимые права; настройку проверим на тестовом сообществе.
Идентификатор сообщества задаётся `/vk НОМЕР` внутри выбранного проекта.

Глобальный VK_ACCESS_TOKEN доступен только администратору, другим пользователям
он не подставляется. Дополнительный вариант — VK_ACCESS_TOKEN_USER_222222222 для
конкретного пользователя; проектный ключ имеет приоритет.

Yandex AI Studio пока общий: генерации всех допущенных участников оплачиваются
из одного аккаунта. Персональных бюджетов и квот пока нет. Демо-режим не делает
платных запросов и запрещает публикацию.
