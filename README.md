# Публикот — Telegram → ИИ → согласование → ВК

Основной стек: **Python 3.12+, aiogram 3, SQLite**. Один проект — бренд с собственной
концепцией, персонажами и аккаунтом ВК. Структура позволяет позднее добавить другие площадки.

## Что реализовано

- Создание и выбор проектов, хранение настроек и персонажей с несколькими фото-референсами.
- Подготовка текста: демо без расходов или адаптер Yandex AI Studio.
- Прикрепление собственной фотографии, предпросмотр, исправление текста и отмена.
- Подтверждение конкретной версии; устаревшие и повторные кнопки отклоняются.
- Адаптер публикации текста и фотографии в сообщество ВК.
- Доступ только владельцу, long polling через HTTP CONNECT / SOCKS5-прокси.
- SQLite сохраняет задания и версии; отправки с неизвестным результатом не повторяются.

**Проверены локальные тесты, включая обработку сообщений через aiogram. Живое
подключение Telegram, Yandex и ВК пока не проверено: нужны ваши настройки и ключи.**

GenAPI и генерация изображений ещё не подключены. Сначала нужно выбрать модель,
проверить её актуальный API, стоимость, оплату картой РФ и поддержку референсов.
Фотографии персонажей пока только сохраняются: модель их ещё не использует.
Планировщика публикаций, фоновой очереди и нескольких владельцев пока нет.

## Локальный запуск

```sh
git clone https://github.com/CanDreamm/The-Loremaster.git
cd The-Loremaster
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python scripts/setup-python.py
.venv/bin/python -m publikot --identify
```

Отправьте `/start` вашему боту. Команда покажет числовой ID отправителя. Укажите
свой ID в `.env.python` как OWNER_TELEGRAM_ID. Не выбирайте чужой ID, если в выводе
несколько отправителей. Токен и пароль прокси вводятся локально, не в чат помощнику.

```sh
.venv/bin/python -m publikot
```

По умолчанию DEMO_MODE=true: генерация бесплатна, текст помечен как демо,
публикация запрещена. Для реального текста задайте YANDEX_API_KEY,
YANDEX_FOLDER_ID и DEMO_MODE=false. Для ВК потребуется VK_ACCESS_TOKEN с правами
на нужные сообщества. Точный тип ключа проверяется при подключении ВК.
В первой версии один ключ ВК используется для всех проектов.

Прокси задаётся только Telegram через TELEGRAM_PROXY. ВК и Yandex идут напрямую.
Домен и публичный HTTPS для long polling не нужны. Запускайте только один экземпляр
бота на один токен. Если остался вебхук n8n, отключите старый workflow и явно выполните:

```sh
.venv/bin/python -m publikot --identify --clear-webhook
```

Эта команда удаляет вебхук бота, не удаляя ожидающие сообщения.

## Проверка

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
```

Тесты не обращаются к внешним сервисам. Они проверяют реальные ограничения SQLite,
обработку сообщений aiogram, согласование и безопасное поведение без ключей.

## Резервное копирование

```sh
.venv/bin/python scripts/backup.py data/publikot.sqlite3 backups/publikot.sqlite3
```

Для копии выберите новый путь. Фото из data/images и data/references и файл
.env.python копируйте отдельно в защищённое хранилище. База используется в WAL-режиме:
не копируйте один sqlite3-файл во время работы бота вместо команды backup.

Развёртывание: [docs/python-deploy.md](docs/python-deploy.md).

## Разработка через Git

Основная ветка — `master`. Код и инструкции обновляются через GitHub.
Локальные `.env.python`, база, фотографии и виртуальное окружение в Git не входят.
Установка и обновление сервера описаны в инструкции развёртывания.
Приложению не нужны n8n, Docker или PostgreSQL.
