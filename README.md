# Публикот — сообщения ВК → ИИ → согласование → публикация

**Python 3.12+, aiohttp, SQLite.** Интерфейс работает в личных сообщениях
[отдельного сообщества ВК](https://vk.ru/club242305804) через **Bots Long Poll**.
Текущий интерфейс работает без Telegram и прокси. Для получения сообщений
публичный вебхук не нужен; для необязательной OAuth-авторизации нужен HTTPS callback.

Проект — один бренд с концепцией, тоном, правилами текста, фото стиля и персонажей.
У проекта несколько площадок и участников. Каждый пользователь подключает свой
Postmypost, выбирает доступные ему аккаунты и добавляет их к проекту. Дзен
подключается отдельно через прямой неофициальный editor API с авторизованным сеансом.

## Проекты и площадки

- «Мои проекты» → «Добавить проект» — создание без OAuth ВК.
- «Мой Postmypost» — личный токен пользователя, зашифрованный в базе.
- Проект → «Площадки» — несколько аккаунтов Postmypost и каналов Дзена.
- Проект → «Участники» — назначение допущенных пользователей владельцем/администратором.
- Общие черновики и согласование сохранены; результат отправки учитывается для
  каждой площадки отдельно, неизвестная отправка не повторяется автоматически.

[Подключение, права, Дзен и инструкция обновления](docs/project-platforms.md).
Транспорт сообщений остаётся ВК. Для публикаций Postmypost/Дзена графический
интерфейс сервера не требуется. Реальные отправки с аккаунтами владельца ещё
не проверены; Дзен — экспериментальный адаптер без стабильного публичного контракта.

Прежний браузерный режим сохранён для совместимости со старыми подключениями:
[инструкция](docs/browser-publishing.md). Новые площадки подключаются через меню выше.

## Реализовано

- Главное меню, список проектов и отдельные меню текста, заданий, настроек,
  площадок и участников. Существующие настройки контента не меняются.
- Личные подключения Postmypost проверяются перед сохранением; списки аккаунтов
  выбираются из сервиса с проверкой доступа. Назначенные участники используют
  подключения проекта без раскрытия чужих токенов.
- По умолчанию ИИ получает указание писать короткий пост до 500 символов;
  объём можно изменить в правилах текста или задании.
- Администратор допускает пользователей по их ID ВК и назначает проекты.
- Участники видят только назначенные проекты, работают с общими заданиями и настройками.
- Текст генерируется через Yandex AI Studio либо в бесплатном демо-режиме.
- В настройках по одному фото визуального стиля и персонажей. Новое фото заменяет старое.
- К заданию можно приложить необязательное фото-референс и описать, что с ним сделать.
  Оно является входным материалом, а не готовой иллюстрацией для публикации.
- Для каждой версии формируются и сохраняются отдельные промпты текста и изображения
  с описаниями материалов и ролями фото. Кнопка «Промпты» показывает оба текста.
  В деморежиме оба промпта присылаются автоматически вместо демонстрационного поста,
  в том числе после исправлений и при повторном открытии задания.
- В «Настройках проекта» доступны «Промпт для текста» и «Промпт для изображения».
  Оба сразу заполнены базовыми текстами; «Изменить» сохраняет свой текст только
  для выбранного проекта. Контекст и задание добавляются автоматически.
  Сохранённые версии заданий при изменении настроек не переписываются.
- В настройках владелец проекта и администратор бота могут удалить проект
  с подтверждением. Удаляются записи настроек, материалов, заданий и подключения
  для всех участников. Уже опубликованные посты в VK остаются.
- Заполненные разделы настроек отмечены ✅. Кнопки удаления и отмены красные
  с ❌, «Назад» и «Главное меню» синие с ⬅️ и ☰, «Добавить сообщество» с ➕.
  Для кнопок-ссылок open_link поле color не отправляется.
- Предпросмотр с исправлением текста, добавлением/заменой фото и отменой.
  Для реального текста с подключёнными площадками доступна кнопка «Опубликовать»;
  перед отправкой проверяется подключение выбранной площадки.
- Исправление текста сохраняет фото, замена фото сохраняет текст; требуется новое подтверждение.
- Публикация текста/фото на несколько площадок через Postmypost и отдельно в Дзен.
  Прежний VK API сохранён для старых подключений.
- Дополнительная команда /connect сохраняет прежнюю OAuth-авторизацию, проверку
  пользователя и прав, зашифрованное хранение ключа по проекту. Для включения
  нужны приложение с wall/photos и публичный HTTPS-адрес возврата.
- Версии, назначения и задания сохраняются в SQLite. Повторные события Long Poll
  не запускают вторую генерацию. Старые кнопки и повторные публикации блокируются.
- Результат отправки с тайм-аутом не повторяется автоматически: сначала проверяется стена.

**Проверено локальными тестами. Реальные сообщения, генерация и публикации
ожидают проверки с вашими ключами.** GenAPI и генерация изображений пока не
подключены. Кнопка изображения позволяет заменить его своей фотографией.
Промпт текста передаётся Yandex; промпт изображения и набор фото с ролями сохраняются
для будущего адаптера изображений. Yandex в этой версии не распознаёт фото;
он получает подписи и сведения о наличии материалов, без выдуманных описаний их содержимого.
Планировщика и фоновой очереди пока нет; входящие команды обрабатываются последовательно.

## Быстрый старт

**Проект уже установлен на сервере?** Сначала откройте
[инструкцию обновления](docs/server-update.md). В ней отдельно описаны установка
от root без службы, установка с пользователем `publikot` и создание службы.
Не клонируйте проект поверх существующей установки и не заменяйте настроенный
`.env.python` файлом примера.

Сначала включите сообщения и Bots Long Poll в сообществе — [инструкция](docs/vk-setup.md).

```sh
git clone --branch master https://github.com/CanDreamm/The-Loremaster.git
cd The-Loremaster
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python scripts/setup-python.py
.venv/bin/python -m publikot --check
.venv/bin/python -m publikot --identify
```

Отправьте `/id` в сообщения сообщества. Команда покажет ID отправителя.
Запишите **свой ID ВК** в OWNER_VK_ID в локальном `.env.python`. Затем:

```sh
.venv/bin/python -m publikot
```

Скрипт настройки работает и с существующим `.env.python`: Enter сохраняет
значение, посторонние настройки не удаляются. Ни ключи, ни пароли в Git не входят.
По умолчанию DEMO_MODE=true: обращения к ИИ и публикация демо-текстов запрещены.
Для реальной генерации нужны YANDEX_API_KEY, YANDEX_FOLDER_ID и DEMO_MODE=false.
Ключи публикаций по проектам: VK_ACCESS_TOKEN_PROJECT_1 и т.д. Ключ VK_BOT_TOKEN
используется только для сообщений и не подставляется в wall.post.

## Проверки и резервная копия

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
.venv/bin/python scripts/backup.py data/publikot-vk.sqlite3 backups/publikot-vk.sqlite3
```

Для каждой копии выбирайте новый путь. Фото из data/images, data/materials, data/references и
.env.python копируются отдельно. SQLite работает в WAL-режиме: не копируйте
один файл базы вместо backup-команды во время работы бота.
Если сохранены ключи публикаций, обязательно сохраните также `data/oauth.key`: без него
ключи из восстановленной базы расшифровать нельзя. Для личных подключений
Postmypost и сеансов Дзена также сохраняйте `data/platforms.key`.

## Переход с Telegram

База ВК — `data/publikot-vk.sqlite3`. Старая `data/publikot.sqlite3` не удаляется
и не открывается новой версией. ID Telegram и ВК не совпадают, поэтому старые
пользователи и назначения автоматически не переносятся. Если успели создать
проекты в Telegram-версии, их содержимое перенесём отдельно с явным назначением
пользователей ВК. Не переименовывайте старую базу в новую.
